协议：ovis_compare_greedy_v1，2026-10-22。只新增服务器版本，本地项目、主方法研究目录、旧代码与历史结果不改。

## 本轮调整

- 原生 Ovis、SpatialPIN-style、ByDeWay 的最终 Ovis 回答统一 max_new_tokens=2048、thinking_budget=1536，thinking 和 thinking_budget 均开启。
- 显式传递 do_sample=False、temperature=1.0、top_p=1.0、top_k=50、repetition_penalty=1.0、num_beams=1。每次内部 llm.generate 解析后的有效配置均核验并审计；不把外层 JSON 当作内部证据。
- 不整包复制外层 GenerationConfig，保留内部 BOS=151643、EOS=151645，pad 回退到 EOS 的真实结果另记。
- 每题/每次外层 Ovis 请求重设 Python、NumPy、torch CPU/CUDA seed42。不悄悄改变 TF32、确定性算法开关，保存实际值。
- 保留 Ovis 动态视觉预处理 448²–1792²、RGB、user 消息、图片在文字前；逐次保存模型可见文字、图像RGB hash、grid、token和dtype。保留方法原生深度图/证据拼图，不声称所有阶段的派生图相同。
- SpatialPIN 对象发现仍为1024、thinking关闭；不把主方法2048的提取预算强加给原本不同任务的对象发现。两个阶段共用冻结的基线专用感知包装，不再依赖随时可能变化的 paper-1-revision 工作区。
- SpatialRGPT 保留原生 VILA 骨干和原生成参数（包括128输出上限），不调用或换成 Ovis；只在新版本统一 SpatialLab 的答案评分协议、种子与审计。
- ByDeWay 的 Depth Anything V2-Large、Kosmos-2、多尺度深度caption流程保留，不加知识、不改工具提示。最终回答旧3072/2048改为2048/1536，因此本版需新运行，不混用旧ByDeWay成绩。
- SpatialLab 评分冻结规范指定的 canonical_evaluation.extract_answer；多标签取最后一个，不扫描思考里的任意数字，按题目有效选项验证。失败保留分母，无按GT反复尝试。
- OmniSpatial、BLINK 的原生版本也在 generalization/ 对齐Ovis，但保留各自官方/已固定字母评分和提示；旧3072/2048结果不覆盖。

## 完整串行评测

两台基线服务器都开卡，仍在29937运行：

```bash
ROOT=/root/autodl-fs/baselines/cost_bench/ovis_compare_greedy_v1
bash "$ROOT/run_all.sh" full --output "$ROOT/runs/full_v1"
```

顺序：原生Ovis -> SpatialPIN -> ByDeWay -> 远程SpatialRGPT。每种1402条（2预热+1400正式）。上一种退出、逐题完整性与内部配置核验通过、GPU worker全部释放后，才启动下一种。末项在另一台机器运行，也等待前三种结束，绝不并发启动四种。

在首次SSH验证时输入44571密码，后续连接安全复用（ControlPersist=48h），不需要把密码存进文件，也不修改服务器authorized_keys。若要长时间离开，建议先在tmux/screen等持久终端中运行；不要第一次就nohup后让SSH密码提示无处输入。

输出目录必须全新；不自动跳过失败题、不静默续跑/混合版本。失败时保留日志并停止后续方法。若需要排查后重启，用新目录，并可用 --methods ovis,spatialpin,bydeway,spatialrgpt 明确指定剩余方法。

运行中每0.5秒检查GPU PID。若发现非本套任务的GPU进程，将自己的本次任务中止并保存 gpu_contamination.json，避免把污染成本当正式记录。它不是调度器对其他用户任务的隔离保证：请勿在测量中途启动别的推理。不会结束无关进程。

## 结果位置

每种方法一个子目录：ovis/、spatialpin/、bydeway/、spatialrgpt/。

- protocol_summary.json：排除预热、完整分母的准确率、有效答案/失败数；优先引用此文件，而非含预热的旧适配器summary。
- cost_summary.json、*.cost.jsonl、*.cost.meta.json：成本、模块计时、模型加载、软件硬件、原始token和源码hash。
- runtime_decoding.jsonl、effective_decoding_calls.jsonl、effective_special_tokens.jsonl：外层/内部配置、每次内部预算与输出、真实pad/EOS。
- visible_inputs.jsonl：完整模型可见文本、消息、图像RGB hash、shape、grid、token；不是仅保存提示词常量。
- launch_manifest.json：机器、数据hash、完整资产锁hash。
- COMPLETED：本方法全部验证通过；总目录ALL_COMPLETED代表四方法都通过。

assets.lock.json包含完整Ovis权重分片及工具权重、代码、数据/图像内容SHA256。每次启动核对冻结文件大小/mtime，变化即拒绝；如需强内容复验（读取大量共享盘，不与正式计时并发）：

```bash
/root/miniconda3/bin/python "$ROOT/assets.py" --deep
```
